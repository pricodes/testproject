# Furniture Showroom

A designer furniture showroom website built with Next.js (App Router), TypeScript, and Tailwind CSS v4.

## Features

- **Responsive Design:** A clean, "designer" aesthetic using Tailwind CSS.
- **Gallery:** Displays furniture pieces in a high-quality grid layout.
- **Lead Generation:** A functional contact form that collects user details (Name, Email, Phone, Interest, Message).
- **API Integration:** Backend API route (`/api/leads`) to handle form submissions.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Navigate to the project directory:
   ```bash
   cd furniture-showroom
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

To start the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

To build the application for production:

```bash
npm run build
```

To start the production server:

```bash
npm start
```
